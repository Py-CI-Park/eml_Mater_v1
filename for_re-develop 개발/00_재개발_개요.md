# 재개발 개요

- 목적: 폐쇄망 환경에서 `.eml` 파일을 빠르고 안전하게 탐색/보기/검색/첨부 다운로드 할 수 있는 로컬 웹앱을, 더 견고한 구조와 유지보수성으로 재설계/구현
- 범위: 백엔드 API, 이메일 파싱/인덱싱, 프론트엔드 UI/UX, 설정/로그/보안, 설치/배포 자동화, 테스트/품질관리
- 비기능 요구: 로컬 전용, 대용량 폴더 대응, 신뢰성/복구성, 일관된 로깅과 에러 처리, Windows 최우선 지원

## 현재 기술 스택 요약 (현행)
- 백엔드: Flask, SQLite, 이메일 파싱(파이썬 표준 라이브러리)
- 프론트엔드: React(CRA), React-Bootstrap, Axios
- 실행: `run.py`로 백/프론트 동시 구동, Windows 배치 스크립트 제공

## 재개발 방향성 핵심
- API 우선 설계, 모듈화, 명확한 경계(파싱/인덱싱/검색/전달 레이어 분리)
- 인덱싱/검색 성능 강화를 위해 SQLite FTS5 도입(오프라인 전용)
- 안전한 파일 접근(루트 고정, 경로 정규화, 확장자 화이트리스트)
- 일관 로그/메트릭, 장애 복구 절차 내장
- 배포/실행 단순화(단일 실행기, 오프라인 설치)

## 결과물
- 정제된 API/데이터 모델/테스트 전략 문서
- 역할별 프롬프트 템플릿으로 반복가능한 개발 흐름 제공
