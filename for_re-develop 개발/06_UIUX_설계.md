# UI/UX 설계

## 정보구조
- 좌: 폴더 트리(루트 고정, 개수 뱃지)
- 중: 이메일 리스트(가상 스크롤 옵션, 정렬/필터)
- 우: 뷰어(HTML/Text 토글, 첨부 리스트/다운로드)
- 상단: 검색바(범위 토글), 설정 진입, 상태 인디케이터

## 상호작용 원칙
- 2클릭 내 열람, 키보드 단축키(위/아래/엔터)
- 로딩/에러/빈 상태 명확 표현
- 긴 텍스트 축약 + 전체 보기 툴팁

## 접근성
- ARIA 라벨, 포커스 링, 대비 준수

## 상태관리 제안
- React Query로 API 캐시/로딩 통합, 전역 store는 최소화
