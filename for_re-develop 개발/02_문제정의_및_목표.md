# 문제 정의 및 목표

## 문제 정의
- 대용량 폴더에서의 검색/목록 로딩 지연
- 경로 처리 보안 강화 필요(루트 이탈, 특수 경로)
- 데이터 계층(태그/상태/인덱스)와 API 미정합
- 운영 가시성(로그/상태/점검) 부족

## 목표 (SMART)
- 성능: 10만 건 .eml 메일 기준, 제목/보낸이/본문 키워드 검색 응답 1s 내 95퍼센타일
- 보안: 루트 밖 파일 접근 0건 보장, HTML 렌더 XSS 0건
- 안정성: 손상 파일/잘못된 인코딩 99% 이상 무중단 처리
- 사용성: 초기 설정 후 3클릭 이내 메일 열람, 다운로드 2클릭 이내
- 운영: 단일 실행(Windows) 기준 시작 ≤ 10s, 상태 점검 엔드포인트 제공
