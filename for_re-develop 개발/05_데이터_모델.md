# 데이터 모델

## 핵심 테이블
- emails (캐시/메타)
  - email_path (PK)
  - subject, sender, recipient, date_parsed, message_id, has_attachments, size_bytes, sha1
- email_status
  - email_path (PK), is_read, is_starred, last_viewed
- tags(id, name, color)
- email_tags(email_path, tag_id) UNIQUE
- user_settings(key, value)

## FTS 인덱스(권장)
- emails_fts (FTS5)
  - email_path, subject, sender, recipient, body_text
  - contentless 또는 content=emails

## 예시 DDL
```sql
CREATE TABLE IF NOT EXISTS emails(
  email_path TEXT PRIMARY KEY,
  subject TEXT, sender TEXT, recipient TEXT,
  date_parsed TIMESTAMP, message_id TEXT,
  has_attachments BOOLEAN, size_bytes INTEGER,
  sha1 TEXT
);

CREATE VIRTUAL TABLE IF NOT EXISTS emails_fts USING fts5(
  email_path UNINDEXED,
  subject, sender, recipient, body_text,
  tokenize = 'unicode61'
);
```

## 인덱싱 전략
- 초기: 전체 스캔 → 헤더 빠르게 + 본문은 지연/요청 시 캐시
- 증분: mtime/size/sha1 변화 감지 후 업데이트
